Ground and ink

Value scale

−maxAbs0+maxAbs

Blue ↔ grey ↔ orange, mixed in OKLab so the midtones stay even. Measured on the surface color: light −1 → 5.9:1, +1 → 4.7:1; dark −1 → 7.6:1, +1 → 7.6:1. Numbers printed on cells switch ink where each theme needs it (light: beyond 85 % of maxAbs, dark: beyond 55 %), so the worst case is 3.7:1 (light) and 4.0:1 (dark) at the crossover. Every cell also carries its exact value as a tooltip.

Glyphs

Each recurring object has exactly one drawing. Values are never encoded by color alone: a number is printed in the cell (36 px and wider; lessons use 40 px) and every cell carries its value as a tooltip. Text on a value fill switches ink by level exactly as cells do.

Stepper

  • Only what changes moves. Each step animates one idea; everything else holds still.
  • Pure frames. Every frame is a function of (step, progress), so scrubbing back and forth is exact.
  • Same axis as the math. Data flows left to right and top to bottom.
  • Reduced motion shows each step's end state instantly.
  • Timing at 1×: 750 ms transitions, 1.8 s rest between steps. Speed (0.5×–2×) divides both.
  • Keys: Space plays, ← → step, when the panel has focus.
